## Автотесты

```bash
python manage.py test
coverage run manage.py test && coverage report
```

Результат: **98 тестов, все проходят, покрытие 98%.**

- `store/tests/test_models.py` — модели и ограничения базы (остаток не может быть отрицательным, один товар один раз в корзине, товар с заказами нельзя удалить, цена в заказе фиксируется).
- `store/tests/test_services.py` — unit-тесты функций из `store/services.py`, вызываются напрямую, без HTTP и авторизации:
  - `add_to_cart`: добавление, суммирование, отказ при нехватке остатка;
  - `create_order`: создание, списание остатков, пустая корзина, остаток кончился, пока товар лежал в корзине;
  - `ship_order`: статус меняется на «Передан в доставку»;
  - `cancel_order`: возврат на склад, запрет отмены отправленного заказа;
  - `get_sent_orders` / `get_pending_orders`: выборки заказов;
  - `can_change_status`: правила переходов (`SimpleTestCase`, без базы).
- `store/tests/test_views.py` — страницы магазина и админки.
- `store/tests/test_commands.py` — management-команды.
- `users/tests/` — пользователь, адреса, регистрация, вход, личный кабинет.
